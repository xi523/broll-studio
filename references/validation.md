# v1.0.0 验证记录

日期：2026-10-20。验证范围是程序和代表性内容，不等于任意脚本的成片美术质量保证。

## 环境

独立 macOS arm64 Python 3.9 虚拟环境；Pillow 11.3.0、NumPy 2.0.2、fonttools 4.60.2、imageio-ffmpeg 0.6.0。使用随包字体，无原作者机器字体依赖。Linux/Windows 未实机验证。

## 行为验证

- 15 种风格 × 横屏1280×720、竖屏720×1280、方形960×960，共45组。
- 每组检查代表性时间点的完整文字排版、字形；同一时间渲染两次像素一致。
- 13类错误输入验证：重复ID、奇数尺寸、NaN时长、负数数据、未知风格、缺少分支根节点、过长文案、缺字、未标注示例数据、倒置原文时间、缺少产品输入、乱序事件、过多代码行。
- 修改了英文换行：优先保留完整单词，超长无空格串才按字形拆分。
- 实际导出15风格新内容合辑60秒、竖屏新脚本11秒；完整解码通过并查看实际MP4关键帧。
- 独立本地扩展注册、用户图片相对路径、音轨补静音、含空格/中文/单引号的路径、帧数和source时间映射通过验证。
- skill元数据通过quick_validate。

可复现结构回归：

```sh
python scripts/selftest.py --out /path/to/qa
```

生成示例视频：

```sh
python scripts/broll.py render assets/examples/all-styles.json --out /path/to/demo
python scripts/broll.py render assets/examples/cooking-portrait.json --out /path/to/portrait
```

语义准确性、审美、字幕与原口播对齐需要每个项目单独检查。原始参考的镜头与材质不声称逐帧等同；新结构/新语言需增加有针对性的验证。
