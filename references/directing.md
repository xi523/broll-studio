# 从口播到动作分镜

## 本次迭代留下的方法

最初三版使用同一段口播、相似章节和卡片，换成暖金、柠檬黄、奶油配色后仍像PPT。用户认可的方向发生在动作升级之后：收藏真的收入容器；拆解真的分离配色、构图和运动层；修改真的拖动控制点并改变轨迹；整理真的合拢成可复用对象。

这些是设计证据，不是下一条视频的固定剧情。那批组件还写死了字体路径、720×1280坐标和原30秒切点，不能直接作为通用模板发布。复用的是“同一对象产生可见变化”和各风格的表现方法。

## 一镜怎样成立

每镜用六项足够具体的描述指导代码：

1. **信息目标**：观众看完多理解了什么，而不只是知道标题。
2. **对象与关系**：主要对象、细节特征、配角与空间位置。纸张需要折角/厚度/叠放关系，机器需要入口/运动部件/出口；不能只靠名称认出来。
3. **前态与后态**：至少明确当前解释需要的差别。例如输入数量没变，组织方式变化；不要无端让对象凭空增殖。
4. **动作链**：准备→作用→反应→落定。主体移动、结构变形、数量转移、路径改变等承担解释；光晕/网格/镜头推进只辅助。
5. **局部时间**：语义锚点与出结果时刻。动作可轻微预备，关键结果落在对应词附近；重要结果留出识别时间，短句不固定套3–8秒。
6. **可实现方式**：已有组件是否真的会做这个动作；如果不会，写新组件或准备必要素材。分镜写了“切开”不等于普通process组件会执行切开。

场景之间尽量让对象或空间关系接续：上一镜分开的零件进入下一镜装配。需要切换尺度/场景时给观众可识别的连接。不要强迫所有镜头连续，也不要每句都清空画面重放标题。

## 同一句话，真正不同的三种风格

原句：“把零散的资料分类，整理成一本随时能查的手册。”（示例文字，无实测口播时间）

| 风格 | 对象与动作 | 运动和材质 | 结果 |
| --- | --- | --- | --- |
| 暖金 | 带不同图案的资料页悬浮散开，被引向同类页簇，最后沿书脊旋转合页 | 深色空间、暖光照亮纸页厚度，弧形引导与缓慢收束；不是仅有金线箭头 | 一本有分区页签的手册翻开到指定页 |
| 柠檬黄科技 | 资料进入分类轨道，感应门识别图案，分流到不同槽位，机械压合成册 | 几何零件、轨道直线位移、对位吸附、小幅回弹，局部剖视显示分类 | 检索指针选择页签，目标页推出 |
| 奶油手绘 | 手绘纸张摊开，剪刀沿分类边界剪开，纸片归堆，胶带/装订线把页连接 | 可见笔迹、裁纸边、纸层阴影、轻微旋转与翻页；不是科技轨道换奶油色 | 手指或书签翻到目标页，保留手绘注释 |

这些机制只适用于“整理资料”的语义。新口播讲散热，不应继续让资料页进机器；要换成热源、散热片、气流与温度状态。

## 跨题材迁移练习

以下是设计用例，不是事实来源，也不是已经实现的组件。实例化时重新核实事实、设计对象和时间。

| 新脚本 | 应演出的变化 | 容易失败的替代 |
| --- | --- | --- |
| “把面团折叠，再压平” | 面团边缘抬起覆盖中心，形成层，擀压后厚度降低、面积改变；手/工具与接触点一致 | 两张“折叠/压平”卡片轮播 |
| “把大任务拆成今天能做的一步” | 大任务以任务堆或具体目标呈现，分出可执行单元，只把当前一项移到工作区；说明这是比喻 | 一条分岔树配励志标题 |
| “雨水经过滤网，杂质被留下” | 水与杂质一起到达滤网，颗粒按示意尺度被截留，水进入容器；不暗示过滤后必然可饮用 | 蓝点穿过任意圆圈，随后打对勾 |
| “换乘时，先到站台，再换另一条线” | 地图上的同一乘客标记沿第一条路线到换乘节点，走连接通道再上另一条线；路线来自输入或标为示意 | 与地理无关的三张站名卡 |
| “别让一次失败变成对自己的全部评价” | 保留完整的作品/人生轨迹，仅局部一块呈现失败，镜头从局部退回整体；这是视觉比喻 | 红色失败字放大后全屏碎裂，反而强化错误含义 |
| “用户数从A变为B” | 用实际输入数值驱动图形变化，保持尺度、单位、时间口径 | 无来源数字滚动，伪造增长趋势 |

同一画风换题材，应换主体和行为；同一题材换画风，应换表现机制。仅换标题或颜色都不能算迁移完成。

## 参考视频怎么学

有可访问原片时，查看连续动作，不凭封面复刻。记录：主体轮廓/材质、前中后状态、构图层级、景别变化、运动路径、缓动、停顿、过渡、文字密度与声音落点。可以整理少量代表性帧帮助对照，但截图不能证明运动一致。

提炼可复用的风格规则，再对当前脚本重写镜头。保留气质与动作语言，不挪用不相关的太阳、戒指、爱心、人物或原声。无法加载参考时说明观察范围，不假装已经看过。

## 实现与节奏取舍

- 少量精心设计的主体，优于大量无语义粒子。主体用轮廓、内部结构、厚度/遮挡/阴影获得可辨性；纸感不等于铺噪点，科技感不等于铺网格。
- 二维对象运动、流程机制、数据图可用Pillow/SVG/Canvas；真正的三维形变、透明反射或人物表演需要合适工具/素材。选择成本与画面目标相称的实现。
- 一个动作需要哪个部位移动，就移动哪个部位；不要用整张画面缩放假装局部机制。笔尖跟随线端、液流起于壶口、指针到达后才触发反馈。
- 横竖屏重排主体、空间路径与文字安全区，不能把720×1280硬拉成1920×1080。三路同时展示的素材还要在实际缩小尺寸下看清，不增加细碎注释。
- 黑金观点字效是明确例外：文字可以承担主体。需要节奏、景深与关键词推进，不能要求它也画成生活场景。
